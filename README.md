# tempfiles

Репозиторий для хранения файлов. Загружай сюда документы, и я смогу их прочитать.

## Как загрузить файлы

1. Открой ссылку: https://github.com/13Foxik/tempfiles
2. Нажми зелёную кнопку **"Add file"** (вверху справа над списком файлов)
3. Выбери **"Upload files"**
4. Перетащи файлы или нажми "choose your files"
5. Внизу нажми зелёную кнопку **"Commit changes"**

Готово!
